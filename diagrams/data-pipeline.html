How the learning data is collected

Grading and analysis happen on the server, not in the browser, so the answer key never ships and the record can be trusted. Each stage writes to its own table. Only the education data is shown here; accounts and identity are out of scope.

A person takes the test
69 questions. Each answer autosaves as they go, so a closed tab resumes where they left off.

What the collected data is for
A first-party learning dataset, growing with every attempt
  • Calibration. Real score distributions sharpen the 1–9 estimate over time, since the official norming tables are not public.
  • Curriculum signal. Which skills are hardest across all applicants, and which prerequisites are most often the real blocker.
  • Did it work. Resource clicks by skill gap show whether the diagnosis actually changes what people go study, which points to where original material is worth building.
